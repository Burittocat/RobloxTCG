# 스크린샷과 데모

루트 `README.md` 가 여기 있는 파일을 그대로 가져다 쓴다. 이름을 맞춰 넣으면 끝이다.

| 파일 이름 | 무엇을 찍나 |
|---|---|
| `battle.png` | 전투 화면 — 필드에 생물이 깔리고 공격 화살표가 떠 있는 순간이 제일 좋다 |
| `home.png` | 시작 화면 (빠른 대전 · 튜토리얼 · AI 연습 · 덱 편집) |
| `deck.png` | 덱 편집 화면 |
| `demo.gif` | 한 턴 정도의 플레이 (없어도 된다) |

## 찍는 법

1. Studio 에서 F5 로 플레이 → `Alt + PrintScreen` 또는 Studio 의 `View → Screenshot`
2. 이 폴더에 위 이름으로 저장
3. 커밋하면 루트 README 에 바로 뜬다

## 크기

- **PNG 한 장에 1MB 를 넘기지 않는다.** git 은 이미지를 통째로 들고 가서
  한 번 커밋한 큰 파일은 지워도 저장소에서 안 없어진다.
- GIF 는 폭 800px · 10초 이내. 그보다 길면 유튜브에 올리고 README 에 링크만 건다.
