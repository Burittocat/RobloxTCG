# 구현된 룰

턴 구조 · 태그 5종 · 코스트 · 멀리건 · 스택. 여기 적힌 상수는 전부 `src/shared/Rules/Config.luau` 에 있다.

---

## 구현된 룰

### 턴 구조 (기획서 그대로)

```
Untap  → 턴 플레이어의 모든 카드 언탭, 코스트 소환 횟수 리셋   (자동)
Draw   → 1장 드로우 (선공 1턴은 생략)                          (자동)
Main   → 코스트 소환 · 생물 소환 · 마법 시전  / 상대는 즉시시전만
AttackPrep  → 공격자 선언
DefensePrep → 수비측: 방어 배정 · 소환(탭) · 마법
Combat → 데미지 동시 해결                                       (자동)
EndTurn→ 생물 피해·버프 정리 → 다음 턴                          (자동)
```

공격자가 하나도 없으면 `DefensePrep` / `Combat` 은 자동으로 건너뛴다.

### 태그 5종

| 태그 | 구현 |
|---|---|
| **신속** | 소환한 턴에 바로 공격 가능. 수비준비 페이즈에서 **언탭**으로 등장해 즉시 방어 가능 |
| **비행** | 지상(비행X) 비원거리 생물은 비행을 **공격도 방어도** 못 함 |
| **도발** | 필드에 있으면 상대는 플레이어를 직접 공격 불가. 비행도 못 무시함 |
| **원거리** | 비행을 공격/방어 가능, 도발 무시. 대신 플레이어 직공 데미지 **절반(내림)** |
| **즉시시전** | 상대 메인 / 본인 메인 / 본인 수비준비에 발동. 스택 위 소환·마법을 무효화하거나 덱으로 되돌림 |

### 코스트

- 덱 60장 중 원하는 만큼 코스트 카드. 턴당 1장 필드에 소환.
- 코스트 카드는 **언탭 상태로 등장**해 그 턴 바로 탭해서 쓸 수 있고, 다음 자기 언탭 스텝까지 언탭되지 않는다.
- 생물/마법을 낼 때 언탭된 코스트 카드가 순서대로 탭되며 지불된다.

### 멀리건 (판 시작 전)

손패가 마음에 안 들면 **한 번, 벌칙 없이** 통째로 바꾼다. 손패를 덱에 되돌려 섞고
같은 장수를 다시 뽑는다. 물리면 그 자리에서 그 사람의 결정은 끝난다 —
새 손패를 보고 또 고를 수 있다면 그건 무료 1회가 아니다.

동시에 묻지 않고 **선공부터 차례로** 묻는다. 각자 자기 손패만 보므로 결과는
동시에 하는 것과 같고, 대신 "지금 누가 결정할 차례인가" 가 `activePlayerId` 하나로
표현된다 — 우선권·화면·AI 가 전부 이미 그것만 보고 있어서 관문을 위해 따로
고쳐야 하는 곳이 없다.

### 덱 순환 — 왜 드로우를 넣었나

2026-09-09 계측(`lune run tests/balance.luau`, AI 자기대국 120판, 같은 시드 집합):

| | 개편 전 | 개편 후 |
|---|---|---|
| 스타터 덱의 드로우 카드 | 0장 | 12장 (통찰 4 · 종군 서기 4 · 서고 개방 1 등) |
| 한 판에서 쓴 덱 | 21.5장 / 60장 | **25.4장 / 60장** (+18%) |
| 턴 시작 손패(판 전체 평균) | 3.42장 | **3.90장** |
| 판 길이 | 29.9턴 | 29.4턴 |

**드로우는 "카드를 얼마나 보는가" 를 고쳤지만 판 길이는 거의 안 줄였다.**
판이 긴 원인은 드로우가 아니라 라이프 30 대비 보드 교착 쪽이고, 그건 밸런스 문제라
따로 다룬다. 60장 덱에 턴당 1드로우면 25턴짜리 판에서 덱의 40% 정도를 보는 게
구조적 상한이다 — 그 이상은 덱을 줄이거나(기획서 60장 유지 결정) 턴당 드로우를
늘려야 움직인다.

`SPL_INSIGHT`(통찰)를 **일부러 즉시시전이 아닌 일반 마법**으로 만든 이유도 여기 있다.
즉시시전으로 두면 AI 든 사람이든 대응용으로 손에 쥐고 있어서 덱이 도는 데 기여하지
않는다 — 실제로 그렇게 만들었다가 계측에서 그대로 드러났다.

### 스택 (즉시시전이 동작하는 방식)

카드를 내면 즉시 효과가 나지 않고 스택에 올라간다 → 상대에게 대응 창이 열린다 →
아무도 대응하지 않으면 해결된다. 그래서 "상대가 소환하려는 생물을 덱으로 되돌리기",
"상대 마법 무효화"가 성립한다. **무효화당해도 지불한 코스트는 환불되지 않는다.**
